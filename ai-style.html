AIとの開発スタイル

何を作るかという方針は自分で決め、手を動かす作業は Claude Code に任せています。その分担と進め方をまとめました。

AI に任せていること

HTML・CSS・JavaScript のコードは Claude Code が書き、書いた内容をその都度説明してもらっています。何を作るか迷ったときは、AI が出す選択肢つきの質問に答えながら、考えを整理しています。色や文字、レイアウトの案を出すのも AI の役目です。

サイトの文章も、自分の回答をもとに AI が書き、自分が読んで確認しています。

自分で判断していること

何を作るか、誰に何を伝えたいかは自分で決めます。本名や写真は載せず、大学名は載せるといった、公開する範囲も同じです。

AI の提案はそのまま使わず、採用するかどうかを選び、直してほしい所は指示します。たとえば、最初はサイト共通のフッターに使った AI を書いていました。しかし使う AI は作品ごとに変わるので、各作品の奥付にだけ書くよう直してもらいました。どこまで作り込んだら公開するかも、自分の判断です。

進め方

作り始める前に、まず質問に答えて方針を固めます。このサイトでは、志望する企業、伝えたいこと、ページ構成、公開する範囲などを、7回に分けた質問で決めました。

作り始めてからは作業を段階に分け、段階が終わるたびに説明を受け、確認してから次に進みます。

記録の残し方

記録は4か所に残しています。作品ごとの奥付には制作時期・使った AI・役割分担を、README には判断の理由を書きます。Git には区切りごとの変更を日付つきで残しています。決めたルールは CLAUDE.md（Claude Code が作業のたびに読む指示書）に書き、次の作品でも守られるようにしています。
