# portfolio-publish: 公開

main にプッシュすると、GitHub Pages ですぐにサイトへ反映される。チェックが通ったときだけプッシュする。

## 手順

1. **チェック**: `npm install`（`node_modules` がなければ）のあと `npm run check` を実行する
   - 失敗したら原因を直して、もう一度実行する
   - 2回直しても通らなければ、プッシュせずに止めて、何が失敗しているかを報告する
2. **表示の確認**: 変更したページを確かめる。Playwright が使えれば webapp-testing の方法で、`npm run serve` を起動して変更したページを開き、PC 幅（1280px）とスマホ幅（375px）のスクリーンショットを撮って崩れがないか見る。使えなければ、確認すべきページの一覧をユーザーに渡す
3. **最終更新日**: 今日の日付で、全ページのフッターの「最終更新」と README の「最終更新日」をそろえる（すでに今日なら何もしない）。日付を変えたら、もう一度 `npm run check` を実行する
4. **コミット**: 変更内容が分かる日本語のメッセージでコミットする
5. **プッシュ**: `git push origin main` を実行する
   - クラウドのセッションなどで作業ブランチが指定されている場合は、そのブランチにプッシュし、main への反映（プルリクエストのマージ）が必要なことをユーザーに伝える
6. **報告**: 公開した URL（https://wataaass.github.io/ と変更したページ）と、確認の結果を短く伝える。反映には1〜2分かかることを添える
