# portfolio-publish

main にプッシュすると GitHub Pages ですぐ公開される。チェックが通ったときだけプッシュする。

1. **チェック**: `node_modules` がなければ `npm install` を実行する。そのあと `npm run check`。失敗したら直して再実行し、2回直しても通らなければプッシュせずに止めて報告する
2. **表示**: Playwright が使えれば、`npm run serve` を起動して変更したページだけスクリーンショットを撮る（webapp-testing の方法）。幅は 1280px、レイアウトや CSS を変えたときは 375px も撮る。使えなければ、確認すべきページの一覧をユーザーに渡す
3. **最終更新日**: 全ページのフッターと README を今日の日付にそろえる（portfolio-edit-common）。変えたら `npm run check` をもう一度実行する
4. **コミット**: 変更内容が分かる日本語のメッセージでコミットする
5. **プッシュ**: `git push origin main`。作業ブランチが指定されている環境では、そのブランチにプッシュし、main へのマージが必要なことを伝える
6. **報告**: 公開した URL（トップと変更したページ）と確認結果を伝え、反映に1〜2分かかることを添える
