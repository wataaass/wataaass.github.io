# portfolio-edit-common

メニューとフッターは各 HTML に直接書いてある（README の設計上の判断）ので、全ページを同じように直す。

**対象**: `*.html` と `works/*.html` のすべて（404.html も含む）。ページは毎回 `ls` で数え、決め打ちしない。

**ページによる違い**: パスの書き方が違うので、同じ文字列での一律置換はしない。
- 直下のページ: そのまま（`timeline.html`、`works/`）
- `works/` の中: `../` から（`../timeline.html`）。作品一覧は `./`
- `404.html`: `/` から（`/timeline.html`）
- `aria-current` は、そのページ（または属する章）のリンクだけにつける

**手順**:
1. `grep -n` で全ページの対象部分を一度に出し、今の書き方と違いを確かめる（ファイル全体は読まない）
2. 書き換える。違いがパスと `aria-current` だけなら、`sed` などでまとめて置換してよい
3. もう一度 `grep` して、そろったことを確かめる
4. `npm run check` を実行し、変更したページ数と、違いをどう扱ったかを報告する
