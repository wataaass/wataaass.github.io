# portfolio-edit-common: 共通部分の一括修正

メニューとフッターは JavaScript を使わず、各 HTML に直接書いている（README の設計上の判断）。そのため、変えるときは全ページを同じように直す。

## 対象のページ

`*.html` と `works/*.html` のすべて（`404.html` を含む）。ページの数は毎回 `ls` で確かめ、決め打ちしない。

## 注意する違い

ページの場所によって、パスの書き方が違う。同じ文字列で置き換えると壊れるので、ページごとに合わせる。

| ページ | パスの書き方 | 例 |
|---|---|---|
| 直下（`index.html` など） | `./` から | `timeline.html`、`works/` |
| `works/` の中 | `../` から | `../timeline.html`、`./` |
| `404.html` | `/` から（どの深さでも崩れないように） | `/timeline.html` |

`aria-current` は、そのページ自身（または属する章）のリンクだけにつける。

## 手順

1. 直す前に、全ページで対象部分を grep し、今の書き方と、ページごとの違いを一覧にする
2. ページごとに書き換える。違いがパスと `aria-current` だけなら、置換をまとめて行ってよい
3. もう一度 grep して、全ページがそろったことを確かめる
4. `npm run check` を実行する
5. 変更したページの数と、ページごとの違いをどう扱ったかを短く報告する
