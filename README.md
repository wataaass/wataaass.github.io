# ポートフォリオサイト

就職活動に向けて、自分の制作物と学習の記録をまとめる Web サイト。
「学び続ける姿勢」と「AI を使いこなす力」を伝えることを目的にしている。

## 制作情報
- 制作期間: 2026-09-30 〜 （制作中）
- 最終更新日: 2026-10-01
- 作者の学年（制作当時）: 広島市立大学 情報科学部 1年
- 使用した AI ツール / モデル: Claude Code（Claude Opus 5.5）
- AI の役割と自分の役割:
  - 自分: 目的・ページ構成・公開範囲などの方針決め、内容の確認
  - AI: 質問による方針の整理、コードの作成と解説、自分の回答をもとにした文章の作成

## ページ構成
| ページ | ファイル | 内容 |
|---|---|---|
| トップ | `index.html` | サイト名と各ページへの案内 |
| 作品 | `works/index.html` | 作品の一覧（制作時期の順に並べた行形式） |
| 作品詳細 | `works/*.html` | 作品ごとの説明、制作時期、AI との役割分担 |
| 学習タイムライン | `timeline.html` | 学習の大きな節目 |
| AI との開発スタイル | `ai-style.html` | Claude Code の使い方と、自分が判断していること |
| ページが見つかりません | `404.html` | 存在しない URL に来たときの案内。どの深さでも崩れないよう、パスは `/` から書いている |

## デザイン
- **テーマ: 本の奥付**。トップを目次、各ページを章、フッターをサイト全体の奥付に見立てる。作品ごとに奥付の形で制作時期・使った AI・役割分担を載せる。
- **色**: 牡蠣殻 `#f6f7f5`（背景）、墨藍 `#1e2a33`（本文）、島影 `#5b6770`（補足）、罫線 `#d5dad8`、瀬戸内の海 `#1f5f74`（リンクと奥付）
- **書体**: 見出しと奥付はしっぽり明朝、本文は BIZ UDPゴシック（Google Fonts）
- **目立たせる場所**: トップの縦書きの題字「制作記録」と、奥付の子持ち罫（太い線と細い線を平行に引いた罫線）の2つ。それ以外は控えめにする。

## 使っている技術
- HTML / CSS / JavaScript（フレームワークなし）
- HTML の文法チェック: html-validate（`npm install` のあと `npm run lint`）
- 確認用のスクリプト（`scripts/`、Node.js）
  - `npm run check`: 文法チェックとリンク切れの確認をまとめて行う。公開前に毎回実行する
  - `npm run links`: リンク切れの確認だけを行う。フォルダ内の HTML を自動で探すので、ページを増やしても書き直さなくてよい
  - `npm run serve`: 確認用サーバーを起動する。ブラウザで http://localhost:8123/ を開くと、公開時と同じ状態で見た目を確認できる
- 公開先: GitHub Pages（https://wataaass.github.io/ 、2026-09-30 公開）

## 設計上の判断
- **フレームワークを使わない**: 仕組みを基礎から理解し、面接で自分の言葉で説明できるようにするため。
- **最初から複数ページにする**: 作品が増えたときに作り直さなくて済むようにするため。
- **自己紹介ページを置かない**: サイトの主役を作品に絞るため。所属はフッターに表示する。
- **本名と写真を載せない**: ネットに公開するため、名前はニックネームにしている。
- **作品一覧は新しい順、学習タイムラインは古い順に並べる**: 採用担当者が最新の作品をすぐ見られるようにするため。タイムラインは成長の流れを追いやすくするため。
- **作品の奥付はページの最後に置き、作品名の下にも制作期間を書く**: 本物の奥付と同じ位置にしつつ、制作時期はすぐ確認できるようにするため。フッター（サイト全体の奥付）は控えめにして、作品の奥付を主役にしている。
- **作品一覧をカードではなく行形式にする**: 制作時期が縦にそろい、作品が増えるほど成長の流れが見えるため。カードを並べる形はよくある型で、印象に残りにくいことも理由。
- **メニューとフッターを各 HTML に直接書く**: JavaScript がなくても表示でき、仕組みが単純になるため。そのかわり、変更するときは全ページを直す必要がある。
- **スマホのメニューは JavaScript が動くときだけ開閉式にする**: JavaScript が動かない環境でも、リンクが全部見えるようにするため。
