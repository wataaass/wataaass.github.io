ポートフォリオサイト

作品と学びの記録をまとめた、このサイトです。

制作期間 2026年9月30日〜（制作中）

作った理由

AI コーディングツールは進化が速く、同じ作品でも、作った時期によって評価が変わります。そこで、何をいつ、どの AI を使って作ったのかを、大学1年生のうちから記録に残しておきたいと考えました。このサイトはその記録の置き場で、これから作る作品もここに加えていきます。

最初の作品に選んだのは、初心者の自分でも小さく始めて、完成まで持っていけると考えたからです。HTML・CSS・JavaScript の仕組みを、実際に作りながら理解したいとも思っていました。

工夫したところ

特にこだわったのは、すべての作品に制作時期・使った AI・自分と AI の役割分担を必ず書くというルールです。ルールは制作の最初に決め、サイトのデザインもそれに合わせました。本の最後にある奥付に見立てて、作品ページの最後に制作の記録をまとめています。

もう一つは、自己紹介のページを置かず、作品紹介に絞ったことです。人柄はエントリーシートや面接で伝えられますし、ネットに公開する個人情報も減らせます。載せるものを絞ると、何のためのサイトなのかがすぐ伝わります。

学んだこと

一番大きかったのは、AI への任せ方です。目的や構成、公開する範囲といった方針は自分で決め、コードを書く作業は Claude Code に任せました。一度にすべてを作らせず、段階ごとに説明を受けて確認しながら進めたので、中身を理解しながら作れました。

作り始める前に、Claude Code からの質問に答えて方針を固めたことも役に立ちました。何を作るかが先に決まっていたので、途中で迷わずに進められました。

技術面では、Git を使うと変更の履歴を日付つきで残せることを知りました。この履歴は、制作時期の証拠にもなります。HTML がページの骨組み、CSS が見た目、JavaScript が動きを受け持つという役割分担も、実際のファイルを見ながら理解できました。
